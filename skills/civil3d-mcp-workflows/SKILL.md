## 0. Pre-flight (always, before any other call)
0. **Start-up:** if port 8080 is closed: `powershell -NoProfile -ExecutionPolicy Bypass -File ~/.claude/skills/civil3d-mcp-workflows/scripts/start-civil3d-mcp.ps1` (opens Civil 3D, waits, NETLOADs by COM, confirms 8080; `-Quit` closes only if no drawing has work). The plugin autoloads through a registry key made by `scripts/install-autoload.ps1` (the `LoadOnAutoCADStartup` bundle does NOT autoload in 2027; redo after a reinstall). Civil 3D needs an Autodesk sign-in: if a "Sign in" window stays, the USER presses **Retry** on the "Opening product" page and "Open" in the Identity Manager box; **never close that window with X (it shuts Civil 3D down)**; never read/paste URLs or codes.
1. `civil3d_health`: check everything, not just `connected`. `drawingLoaded:false` = no focused document. `operationInProgress:true` with `currentOperationDurationMs` > ~30 s = a **modal dialog is blocking Civil 3D**: stop and ask the user; never retry in a loop. `queueDepth` near `queueCapacity` = wait.
2. `acad_list_open_documents`: confirm the right DWG is open; else `acad_set_active_document { match }`. To open a DWG: `Start-Process "<path>.dwg"` or `civil3d_drawing new templatePath=<dwg>` + `save saveAs=<same path> overwrite:true`. **Never** activate/save a file the user has open with changes (e.g. their guide).
3. `get_drawing_info`: note `unsavedChanges`. If already `true` before you edit, there is unreviewed human work: Save As to a dated folder instead of saving in place.
4. If anything fails: `references/troubleshooting.md` BEFORE retrying. Quick diagnosis: `scripts/c3d-health.ps1`.

## 2. Golden rules
1. **Read before writing.** Every edit starts from an `acad_list_*`/`get` that returns the `handle` and current raw value. Never edit from memory or a previous session's summary.
2. **Cheap filters first:** `acad_list_text_entities { contains }` before listing everything; use `layer`, `space`, `nearX/nearY/nearRadius`, `limit`.
3. **Large outputs -> script, not context:** `node scripts/summarize-entities.mjs <file> [--by layer|color|type] [--contains TEXT]`.
4. **Mutations need approval.** `civil3d_request_approval { toolName, action, parameters }` -> token; call the tool with EXACTLY the same parameters + `approvalToken`. The token is exact per parameters (byte for byte), per drawing state (hash of `get_drawing_info`) and expires in 5 min: request a fresh one right before EVERY write; on "does not match" do not debug, re-request. `civil3d_preview_action` says whether an action needs approval.
5. **Writes in the main session, not in subagents** (auto-mode denies subagent mutations). A subagent returns tool + exact parameters + handles.
6. **Verify the truth, not only the match.** A station/offset/coordinate/sheet number in text is a physical claim: check it against the drawing (`civil3d_alignment station_to_point`, nearby geometry). If PDFs agree but the drawing does not, tell the user.
7. **Edit the substring, keep the format** (MText codes `\P`, `\f...;`, `\H...;`, real tabs). Fix spelling/punctuation of NEW text; flag (do not propagate or silently "fix") an error in the source PDF.
8. **Near-identical stations** (10+30.52 vs 10+35.52 at the same offset) are different objects: compare the full station string.
9. **Save when each sheet is done** (`civil3d_drawing save`, needs token). If it had prior `unsavedChanges`: ask, Save As to a dated folder.
10. **Deleting is the user's decision** (`acad_erase_entity`, `acad_purge_unused`): explicit confirmation only; "suspicious" duplicates are reported, not deleted.
11. **Duplicate DWGs:** if Glob finds more than one copy, ask which is live.
12. **Steps without a tool are manual:** opening DWGs, Batch Plot, Sunshine 811, EOR PDF review. Say so; no workarounds.
13. **Stale sub-tasks:** if a sub-task depended on a premise that proved false, ask whether it still applies.
14. **MDWASD standards = county law (data cleaning AND design proposals).** Easements, water/sewer separations, MH spacing, mandatory labels and record-drawing requirements come from Miami-Dade WASD standards (UC-005, GS 0.5, GS 1.5, WS 2.21, UC-250, UC-310), coded in `references/standards/mdwasd-standards.json` (human: `mdwasd-standards.md`; detail measures: `mdwasd-details.md` + `standards/mdwasd-thrust-restraint.json` + `standards/mdwasd-abbreviations.json`; plugin `civil3d_standards_lookup topic:"mdwasd"`). **Existing (Fase 1):** standards are used to LABEL and VERIFY (`mdwasd-check.mjs`, runs inside `fase1-qc.py`), never to move/"correct" an as-built value; an MDWASD easement is drawn only if the pipe is on private property (`c300-mdwasd-easement.mjs`); the RECORDED easement (plat/O.R., user-confirmed) beats the standard strip. **Proposal (design):** place pipes/MHs/valves/hydrants to meet the numbers (water 12 ft = 6 each side, sewer 15 ft = 7.5 each side, both >= 23.5 ft with 10 ft between; horizontal water-sewer separation 10 ft preferred / 6 ft min; vertical crossing >= 12 in; MH <= 400 ft; appurtenances outside the easement) and run `mdwasd-check.mjs` before delivering. If MDWASD revises a section: update the JSON + `rev`, the plugin rule and memory `mdwasd_standards`.

15. **Deliveries (user 2026-10-26, after three zips went out without the DWG):** (a) SAVE every open drawing first and refresh the PDFs; (b) the zip MUST contain `<Name> @xereft base.dwg`: `package-base.mjs --zip` stages a copy (Civil 3D locks the open DWG and `Compress-Archive` silently skipped it) and exits 1 with `ZIP INCOMPLETE` otherwise; open the zip and compare top-level entries and sizes with the folder before uploading; (c) REPLACE, never version: one zip per folder (intake / base / proposed) in Drive and ONE release per folder in the private repo (fixed tags, `project-backup.mjs --release` replaces the asset); (d) after each Drive replace delete the old versions (Administrar versiones > Borrar > Borrar definitivamente; never "Versión actual", never "Conservar ambos archivos"); (e) deleting something already shared needs the user's word, but he gave it for these. Procedure: `scripts/gdrive-update-zip.md`; command `/entrega`.
