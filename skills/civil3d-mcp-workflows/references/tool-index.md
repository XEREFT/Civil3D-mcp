# MCP tool index by domain

"When to use what" table. Exact parameters: `list_tool_capabilities` or load the schema with `ToolSearch select:<tool>`.
Snapshot: plugin 1.2.1 + 15 `acad_*` added Jul-Aug 2026 (~220 tools, 29 domains). The repo's `docs/tools.generated.md` is **outdated** (no `acad_*`): trust `list_tool_capabilities`.

**Convention:** each domain has an **aggregate** tool `civil3d_<domain>` with an `action` parameter plus single-action **aliases** (`civil3d_<domain>_<action>`). Equivalent; the aggregate saves schemas when using several actions.
**Approval:** every action that creates/edits/deletes/imports/exports/saves needs `approvalToken` (SKILL.md). Reads (`list`, `get`, `report`, `check_*`) do not.

Contents: 1 System/documents · 2 AutoCAD basics (`acad_*`) · 3 Alignments · 4 Profiles · 5 Pipes · 6 Surfaces · 7 Grading · 8 Corridors/sections · 9 Parcels · 10 Points/COGO/survey · 11 Hydrology · 12 Labels/styles/standards · 13 QC · 14 Quantities · 15 Sheets · 16 Project · 17 Workflows · 18 Entry template + local registry.

## 2. AutoCAD basics (`acad_*`, geometry domain)
Everything by hex **handle**. Rotations in **radians**.
| Tool | When | Minimum payload |
|---|---|---|
| `acad_list_text_entities` | Find DBText/MText/MLeader by content; step 1 of any note correction. | `{ contains:"TAPPING SLEEVE", space:"all" }` |
| `acad_update_text_content` | Change text, position, height, rotation. MLeader: `text`, `height`, `x`/`y` (text), `rotation`, `leaderX`/`leaderY` (arrow tip). MText accepts `backgroundMask:true`. | `{ handle:"52D33", text:"<raw edited>" }` |
| `acad_create_mleader` | New callout with arrow; `leaderPoint` = arrow tip, `textPoint` = text location; accepts `space`/`layout` (paper units on paper). | `{ text, leaderPointX, leaderPointY, textPointX, textPointY, layer?, mLeaderStyle?, textHeight?, space?, layout? }` |
| `acad_create_text` | Loose DBText; **model space** by default, `space:"paper"` + `layout` for layouts (title blocks, revision tables). | `{ text, x, y, height?, layer?, space?, layout? }` |
| `acad_create_mtext` | MText (multiline, `\P`); same `space`/`layout`; `backgroundMask`, `backgroundScale` (1.2 streets / 1.0 subject). | `{ text, x, y, width?, textHeight?, layer?, space?, layout? }` |
| `acad_erase_entity` / `acad_erase_entities` | Erase by handle **only with user confirmation**; the plural does up to 500 in 1 call, 1 transaction, **1 approval** (`{ handles:[...], ignoreMissing?:true }`; order matters for Civil pieces: pipes before structures; already-cascade-deleted handles go to `skipped`). | `{ handle }` |
| `acad_list_polyline_entities` | Polylines/splines: revision clouds, contours; filter `layer`/`colorIndex`; noisy on PDF-underlay layers (`PDF##_*`): summarize with `summarize-entities.mjs`. | `{ space:"all", colorIndex:1 }` |
| `acad_list_shape_entities` | Line/Circle/Arc/Ellipse/Solid/Hatch/Point for hand-drawn symbols or PDF underlay; always with proximity. | `{ nearX, nearY, nearRadius:5 }` |
| `acad_list_dimensions` | Aligned/rotated dimensions: measurement, override, style, definition points; to read survey R/W widths. | `{ layer:"DIM" }` or `{ nearX, nearY, nearRadius }` |
| `acad_create_aligned_dimension` | DIMALIGNED between 2 points (CL -> R/W). `dimStyle` must exist; `textOverride` with `<>` keeps the value; annotative style -> one scale (CANNOSCALE); `dimTad`/`dimTxtDirection` = DSTYLE overrides (firm: 4 / true on rotated plans). `offset` 0 leaves the dim line on the measured points. | `{ x1,y1,x2,y2, dimStyle:"BCC-1.0", layer:"C-ANNO", offset }` |
| `acad_list_viewports` / `acad_set_viewport_twist` | Layout viewports: scale (`1"=20'`), twist (DVIEW TW), model-space center, lock, `annotationScale` (`"1\" = 20'"` = good; `"1\" = 1'"` = annotative dims/MLeaders invisible, fix; `null` = sheet viewport, correct). Twist = 360 - theta to make the street horizontal; keeps the center unless `centerX/Y`; sets `ViewTarget` = center and `ViewCenter` = 0,0. | `{ layout:"C-300" }` / `{ layout, streetAngleDegrees }` |
| `acad_create_entities` | **Batch**: line/polyline/text/mtext/mleader/aligned_dimension/block/viewport with layer, color, linetype, ltscale, lineweight, styles; creates missing layers from `layers`; 1 approval; all-or-nothing. Apply `standards/*.json` or a `replay-from-package.cjs` payload. mleader: `x/y` = text location, `width`, `rotation` (street angle); dim: `dimTad`, `dimTxtDirection`. Viewport (paper only): x/y paper center, width/height, targetX/targetY, scale (0.05 = 1"=20'), twistDegrees, locked; gets the matching annotation scale. With `space:"model"` and any mleader/dimension it switches to the Model tab first. `rotation` radians; `attachment` 1-9 (2 = TopCenter); `colorIndex` 256 = ByLayer. Block definition must exist (else `acad_insert_block_reference` with `sourceFilePath` first). Annotative MLeader style (Formtech-1.0): do not pass `scale` (eInvalidContext); `rotation` is fine. MText tab = real TAB (JSON `"\t"`). | `{ layers:{...}, entities:[{kind:"mtext",layer,textStyle,height,attachment,rotation,text,x,y}, ...] }` |
| `acad_move_entities` | Move by handles (model or paper) with dx/dy. | |
| `acad_select_entities` | Leave entities SELECTED by handle (implicit selection = user sees them highlighted) and zoom Model (`zoom` default true, `zoomMargin` 1.5; respects twist; switches to Model). Read-only. Show a proposal to the user (e.g. the U.E. line). | |
| `acad_list_block_references` | INSERTs (effective name of dynamic blocks); also lists xrefs. WASD symbols are usually NOT blocks: if empty, use `acad_list_shape_entities`. | `{ contains:"valve", includeAttributes:true }` |
| `acad_update_block_reference` | Change symbol (`blockName` already defined), position, scale, attributes. | `{ handle, attributes:[{tag,value}] }` |
| `acad_insert_block_reference` | Insert a block; with `sourceFilePath` imports the definition from a DWG library. | `{ blockName, x, y, layer?, sourceFilePath? }` |
| `acad_create_or_update_layer` | Create/update a layer (ACI color, linetype, lineweight in 1/100 mm, plot, freeze, lock). | `{ name:"XREF", colorIndex:7 }` |
| `acad_list_layers` | LIVE layer state (frozen/off/locked, color, linetype, xref-dependent). Xref layers appear as `XREF|LAYER` with `isXrefDependent:true`. Needs the new DLL (else METHOD_NOT_FOUND). | `{ name?, namePattern?:"X-UTIL|*", includeXref?:false, limit?:2000 }` |
| `acad_attach_xref` | Attach an xref; **Overlay by default**. May be blocked by the auto-mode classifier: add `mcp__Civil_3D_MCP__acad_attach_xref` to `permissions.allow` and `autoMode.allow` in `.claude/settings.local.json`. | `{ filePath, layer:"XREF", x:0, y:0 }` |
| `acad_purge_unused` / `acad_audit_drawing` | Real PURGE (disposable files, with confirmation) / real AUDIT (safe; via `Editor.Command`). | `{}` / `{ fixErrors:true }` |
| `acad_create_polyline` / `acad_create_3dpolyline` / `create_line_segment` | Lines and polylines. | see schema |

| `civil3d_geometry` | Aggregate: COGO + all the above via `action`. | |

## 3. Alignments
`civil3d_alignment`: `list`, `get`, `report`, `create`, `delete`, `add_tangent`, `add_spiral`, `delete_entity`, `set_style`, `offset_create`, `widen_transition`; **`station_to_point`** (`{ name, station:1030.52, offset:-6.68 }` -> XY: locate a callout); **`point_to_station`** / `civil3d_alignment_get_station_offset` (XY -> station/offset: verify what a text says); `civil3d_alignment_set_station_equation` (move 0+00 / round the final station). `civil3d_intersection`, `civil3d_superelevation*`: rarely used in water connections. `civil3d_pipe_network_delete` removes a whole **gravity** network or its empty shell (`PROP SAN SEWER`); pressure: `civil3d_pressure_network_delete`.

- Payload: `{ templatePath?, saveAs?, overwrite?, expectedDocument?, xrefs?:[{filePath,layer?,overlay?}], alignment?:{name,points,style?,labelSet?,layer?}, clImport?:{blockName,sourceFilePath}, blockImports?:[{blockName,sourceFilePath}], entities?:[...] (acad_create_entities format), layers?, freezeLayers?:string[] (xref layers to freeze right after the xrefs; the payload script sets ["X-TOPO|DIM"] from roles.fase1.freezeXrefLayers; survey without it = "nothing to hide", not an error), entitySpace?, entityLayout?, twists?:[{layout,viewportHandle?,streetAngleDegrees,centerX,centerY}] (C-300 without handle = largest viewport; Model with center = alignment midpoint), titleBlock?:[{layout,contains,find,replace}], stripPropNotes? (default true), sheet?:{minX,minY,maxX,maxY} (default ARCH D 36x24), save? (default true) }`.
- Order: open template -> **check new drawing is active** -> save as -> **check active document** (= `expectedDocument` or `saveAs`; with neither it refuses to write) -> xrefs -> **freeze `freezeLayers`** -> alignment -> `_cl` -> entities -> twists -> title block (filtered by layout TS-side; fragment matching > 1 text -> FAIL) -> **Fase 1 notes** (erases PROP notes off-sheet, rewrites the sheet's MD-WASD note with `fase1PropNotes.ts`, measures the note before/after and lifts with `moveEntities` what is left in the emptied strip (the "(NOT PART OF M-WASD NOTES..." glyphs); any other PROP text on the sheet -> FAIL, touching nothing) -> **check active document before save** -> save.
- `expectedDocument`: file name (compared ONLY against the name, never the folder) or full path. Called alone with `{ expectedDocument }` = cleans that drawing's PROP notes and saves (one-call fix of the audit FAIL "PROP/PROPOSED in paper space").
- Stops at the first FAIL; the rest is `skipped`; nothing is undone or duplicated automatically: read `outputs.steps[]`, never blindly retry the whole payload.
- Approval: `toolName:"civil3d_workflow_fase1_build"`, `action:"fase1_build"`, `parameters` = payload without `action`, byte-identical in both calls (read it from `payload.json`).
- Live-validated 2026-09-28/10-01 on VILLA ONE scratch copies: 15/15 OK + audit 9 OK in ~10 s, identical to the real FASE 1.dwg for what the spec covers (440.00 ft `BCC - ALIGNMENT`, `CDF1` 268.4891° `1" = 20'`, Model 268.4891°/SNAPANG 91.5109, xrefs `.\X-*.dwg` overlay, `_cl` at 0.01 ft; 45 glyphs lifted +7.621).
